## Summary
- Reworks the Blender backend as a render-only handler that pairs with any physics handler via `HybridSimHandler`. Cycles output (RGB / depth / normal / instance_seg) wired through the Blender 5.x compositor API (`compositing_node_group`, per-pass `OPEN_EXR_MULTILAYER`, GPU auto-detect).
- URDF + FK loaded directly with `xml.etree` + `trimesh`; per-region PBR materials and textures preserved (no glTF round-trip / no double Z-up rotation).
- Stand-alone augmentation utilities under `metasim/sim/blender/utils/`: HDRI / sun / ground / colour world (`scene_aug`), material-library and procedural PBR (`material_aug`), camera / pose / DOF samplers (`randomize`).
- Threads `normal` through `CameraState`; registers `mesh` (rigid) and `urdf` (articulation) as Blender file types so existing `roboverse_data` assets work unchanged.
- `asset_paths.py`: heavy assets (HDRI lib, `material_lib_v2.blend`) are looked up locally, then auto-fetched from `RoboVerseOrg/roboverse_data/blender/` on HuggingFace -- nothing large lands in the repo.
- `get_started/blender_demo.py`: one consolidated end-to-end example -- HybridSim (mujoco + blender) replays a manipulation trajectory under randomised HDRI lighting (and optional material re-skinning), writing one mp4 per replay.
