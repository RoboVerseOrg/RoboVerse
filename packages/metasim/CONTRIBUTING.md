# Contributing to MetaSim

MetaSim lives in the RoboVerse monorepo. Read [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md) for setup, PR rules and CI, and this directory's [`AGENTS.md`](AGENTS.md) for the core-specific development rules (handler contract, test markers, backend environments).

Install from the repo root: `python -m pip install -e "packages/metasim[dev,examples,mujoco]"`; run the simulator-free suite from this directory with `python -m pytest -k general`.
